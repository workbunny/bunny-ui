DatePicker 日期选择器

日期选择器支持多种模式：日期、日期+时间、纯时间、年月、年份选择，以及两个输入框联动的时间区间。

时间区间

  • Preview
  • Code

两个输入框联动，开始时间不会晚于结束时间。

至 
<div>
    <input class="bny-input" id="range-start"
        dt-picker="date" dt-picker-range="#range-end"
        placeholder="开始日期">
    <span>至</span>
    <input class="bny-input" id="range-end"
        dt-picker="date" dt-picker-range="#range-start"
        placeholder="结束日期">
</div>

键盘交互

  • Preview
  • Code
打开日期面板后：
  • ←/→：前一/后一日（月份视图下切换月份）
  • ↑/↓：上一周/下一周（月份视图下切换年份）
  • Enter：确认选择
  • Escape：取消并关闭
关闭面板后自动触发 input 的 change 事件，便于配合 hx-trigger="change" 提交。 
<input class="bny-input" dt-picker="date">
<input class="bny-input" dt-picker="datetime" dt-picker-range="#dt-end">

API

属性（配置）

属性 值 说明
dt-picker date 日期选择（默认）
dt-picker datetime 日期 + 时分秒
dt-picker time 纯时间选择
dt-picker year-month 年月选择
dt-picker-range #other-id 区间联动，指向另一个 input 的 CSS 选择器；该 input 自动初始化为相同模式并互相约束 start ≤ end
class="bny-input" — 触发器：在普通 <input> 上加此 class，配合 dt-picker 即被自动初始化

CSS 类名（生成结构）

类名说明
.bny-datepicker-wrap自动包裹触发 input 的外层容器（可定位/主题化）
.bny-datepicker-panel弹出面板；附加 .show 时显示，.mode-time 时纯时间布局
.bny-datepicker-calendar日历表格区域
.bny-datepicker-time时分秒调节区域（datetime / time 模式）
.bny-datepicker-footer底部按钮区（今天 / 取消 / 确定）
.day-cell日期格；状态修饰 .selected / .today / .disabled / .other-month
.bny-datepicker-btn底部按钮；.today / .confirm / .cancel 区分三种操作
点击标题可在日历 → 月份 → 年份面板之间切换。点击"今天"快捷填充当前时间，💜 确认生效，取消关闭。关闭面板后自动触发 input 的 change 事件，便于配合 hx-trigger="change" 提交。
