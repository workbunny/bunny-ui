Carousel 轮播

轮播组件，容器加 hx-ext="bny-carousel" 后其直接子元素自动成为轮播项。 支持箭头 / 指示器 / 自动播放 / 循环 / 键盘操作 / 跟手拖拽，提供 slide / fade / coverflow（异形 3D）三种切换效果， 自动播放支持离散跳格与 smooth 丝滑连续滚动，也可由服务端返回 JSON 自动渲染。

基础用法

  • Preview
  • Code
容器加 hx-ext="bny-carousel" 后，其直接子元素（如 img 或任意元素）自动成为轮播项； carousel-height 指定轮播高度。左右箭头悬浮时显示，点击底部指示器可跳转对应项。 
<div hx-ext="bny-carousel" carousel-height="320px">
    <img src="https://picsum.photos/seed/c11/800/400" alt="山间晨曦">
    <img src="https://picsum.photos/seed/c12/800/400" alt="城市夜色">
    <img src="https://picsum.photos/seed/c13/800/400" alt="海岸风光">
</div>

手动拖拽

  • Preview
  • Code
支持鼠标 / 触摸跟手拖拽（Swiper 风格，slide / coverflow 效果）：
  • 释放时按位移（超过 1/3 视口宽）或速度吸附到相邻项，未超阈值回弹
  • 非循环模式拖到边界时有橡皮筋阻尼
  • 拖拽不会误触轮播项内的链接
  • 轮播聚焦后可用键盘 ← / → 切换
<div hx-ext="bny-carousel" carousel-height="320px">
    <img src="https://picsum.photos/seed/c21/800/400" alt="晨雾山峦">
    <img src="https://picsum.photos/seed/c22/800/400" alt="霓虹街景">
    <img src="https://picsum.photos/seed/c23/800/400" alt="静谧海滩">
    <img src="https://picsum.photos/seed/c24/800/400" alt="原始森林">
</div>

// 拖拽默认开启，carousel-drag="false" 可禁用

自动播放

  • Preview
  • Code
carousel-autoplay="3000" 每 3 秒自动切换到下一项；鼠标悬浮时暂停，移开后继续。 
<div hx-ext="bny-carousel" carousel-height="320px" carousel-autoplay="3000">
    <img src="https://picsum.photos/seed/c31/800/400" alt="高原湖泊">
    <img src="https://picsum.photos/seed/c32/800/400" alt="古镇巷陌">
    <img src="https://picsum.photos/seed/c33/800/400" alt="星空夜幕">
</div>

fade 效果

carousel-effect="fade" 切换为淡入淡出效果（默认 slide）； fade 模式下不启用拖拽，建议配合 carousel-height 指定高度。

非循环模式

  • Preview
  • Code
carousel-loop="false" 关闭循环（默认开启）：到达边界后对应箭头禁用； 拖拽到边界时产生橡皮筋阻尼，松手回弹。

箭头与指示器配置

  • Preview
  • Code
carousel-arrow="always" 箭头常显（默认 hover 悬浮显示，另可选 none 隐藏）； carousel-indicator="outside" 指示器显示在轮播下方（默认 inside 浮在轮播内，另可选 none 隐藏）。 
<div hx-ext="bny-carousel"
     carousel-arrow="always"
     carousel-indicator="outside"
     carousel-height="320px">
    <img src="https://picsum.photos/seed/c61/800/400" alt="云端大桥">
    <img src="https://picsum.photos/seed/c62/800/400" alt="梯田光影">
    <img src="https://picsum.photos/seed/c63/800/400" alt="峡谷激流">
</div>

JSON 数据渲染

  • Preview
  • Code
容器加 hx-get 指向返回 application/json 的接口（配合 hx-trigger="load" 页面加载即请求）， 服务端返回的数组自动渲染为轮播项。数据项格式：
  • { src, title, link, target }：图片 + 底部标题浮层 + 可选整项链接（title / link / target 均可选）
  • { html }：任意可信 HTML 内容
  • 字符串 / 数字：转义后的纯文本项
<div hx-ext="bny-carousel"
     hx-get="/test/data/carousel.json"
     hx-trigger="load"
     carousel-height="320px"></div>

// 接口返回（Content-Type: application/json）
{ "data": [
    { "src": "a.jpg", "title": "第一张", "link": "/a", "target": "_blank" },
    { "html": "<p>任意可信HTML内容</p>" },
    "纯文本项"
] }

coverflow 效果（异形 Slide）

  • Preview
  • Code
carousel-effect="coverflow" 异形 3D 覆盖流：中央项正面朝前，两侧项透视旋转 + 缩小 + 压暗，错层堆叠。 支持拖拽 / 箭头 / 指示器 / 自动播放 / 循环环绕（按取模无缝环绕，无需克隆）。 
<div hx-ext="bny-carousel"
     carousel-effect="coverflow"
     carousel-height="320px"
     carousel-autoplay="3000">
    <img src="https://picsum.photos/seed/c81/800/400" alt="城市天际线">
    <img src="https://picsum.photos/seed/c82/800/400" alt="雪山倒影">
    <img src="https://picsum.photos/seed/c83/800/400" alt="落日余晖">
    ...
</div>

丝滑滚动播放

  • Preview
  • Code
carousel-autoplay="smooth" 丝滑连续滚动（默认 60 px/s，carousel-speed 调速）：
  • 循环模式下匀速滚动、到末项后无缝环绕回首项（slide 自动挂克隆项，coverflow 按取模环绕）
  • 非循环模式滚动到边界后乒乓反弹；fade 效果不支持连续滚动，退化为 3000ms 离散切换
  • 鼠标悬浮 / 拖拽期间暂停，移开 / 松手后继续；指示器随滚动实时联动
<div hx-ext="bny-carousel"
     carousel-autoplay="smooth"
     carousel-speed="80"
     carousel-height="320px">
    <img src="a.jpg" alt="晨光熹微">
    <img src="b.jpg" alt="碧海蓝天">
    ...
</div>

// coverflow + smooth 组合
<div hx-ext="bny-carousel"
     carousel-effect="coverflow"
     carousel-autoplay="smooth"
     carousel-speed="60"></div>

API

属性

属性说明
hx-ext="bny-carousel"启用轮播，容器直接子元素自动成为轮播项
carousel-index初始索引，默认 0
carousel-autoplay自动播放：间隔 ms（如 3000）或 "smooth"（丝滑连续滚动）；缺省或 "false" 禁用；鼠标悬浮暂停
carousel-speedsmooth 滚动速度（px/s），默认 60
carousel-loop循环模式，默认开启；"false" 关闭（到边界箭头禁用，拖拽有橡皮筋阻尼，smooth 乒乓反弹）
carousel-arrow箭头显示：hover / always / none（默认 hover）
carousel-indicator指示器：inside / outside / none（默认 inside）
carousel-effect切换效果：slide / fade / coverflow（异形 3D，默认 slide）
carousel-height轮播高度（如 320px）
carousel-drag手动拖拽，默认开启；"false" 禁用（slide / coverflow 效果）
hx-get指向返回 application/json 的接口，返回数组自动渲染轮播项
