属性

bny-attr：对属性名与属性值做增删改查，无需手写 JS。 属性前缀 attr-*；禁止 on* 事件属性与 javascript:/vbscript: 危险值。

注入防护

以下声明会被禁止：目标不会生成 onclick、href 不会变成 javascript:，也无脚本执行（控制台有拦截警告）。

目标 · onclick 应始终不存在
点击上面按钮后，此链接 href 应仍为 #

属性值 的增删改查

  • Preview
  • Code

增/改：attr-set 写入或覆盖 · 追加：attr-add（不重复）· 删：attr-remove="k:v" · 查：getAttribute/attr-applied

目标元素

当前 data-state：（无） · class：（无附加）

多值属性（如 data-tags）按单个值操作： attr-add / attr-remove(单值) / attr-replace="old@new"

tags：hot new 
<!-- 值的增 / 改 / 追加 / 删 -->
<button hx-ext="bny-attr" hx-target="#box" attr-set="data-state:open">增值</button>
<button hx-ext="bny-attr" hx-target="#box" attr-set="data-state:done">改值</button>
<button hx-ext="bny-attr" hx-target="#box" attr-add="class:active">加值</button>
<button hx-ext="bny-attr" hx-target="#box" attr-remove="class:active">删值</button>

<!-- 查值：业务 getAttribute -->
const v = document.getElementById('box').getAttribute('data-state');
<!-- 或监听扩展派发的 attr-applied 事件 -->
box.addEventListener('attr-applied', () => console.log(box.getAttribute('data-state')));

配合 htmx 请求

  • Preview
  • Code

hx-trigger 可填任意事件名（含 htmx 事件）。注意 htmx:afterSwap 派发在目标元素， 因此把 attr 放在目标自身（#req-box）上监听：请求完成替换内容后，给自身加 active 并写 data-loaded。

请求返回的内容会替换到这里，同时因 hx-trigger="htmx:afterSwap" 而高亮

请求后 data-loaded：（尚未请求） 

<!-- htmx:afterSwap 派发在目标元素，attr 放目标自身监听 -->
<button class="bny-btn" hx-get="/data/table01.json"
    hx-target="#box" hx-swap="innerHTML">加载</button>

<div id="box" hx-ext="bny-attr"
    hx-trigger="htmx:afterSwap"
    hx-target="#box"
    attr-add="class:active"
    attr-set="data-loaded:true">...</div>

<!-- 请求元素自身无需声明触发：请求完成后自动应用 -->
<button class="bny-btn" hx-ext="bny-attr" hx-get="/api/status" hx-swap="none"
    attr-json="data" hx-target="#box">拉取状态</button>

<!-- 失败标记等"仅某 htmx 事件"场景：把扩展放在非请求元素上监听（htmx 事件冒泡） -->
<div hx-ext="bny-attr" hx-trigger="htmx:responseError" hx-target="#other" attr-add="class:error">
    <button class="bny-btn" hx-get="/data/xxx">请求</button>
</div>

一对多目标（逗号分隔 / all 前缀）

  • Preview
  • Code

hx-target 支持一对多：逗号分隔多个目标片段，或用 all x 前缀批量选取（querySelectorAll）；每次应用时实时解析，动态节点也能命中。 注意：元素自身带请求属性时 hx-target 归 htmx 交换所有，须单个目标。

目标 A（#multi-a）
目标 B（#multi-b）
all 批量目标 1（.multi-item）
all 批量目标 2（.multi-item）
<!-- 逗号分隔多目标 + all 批量选取（同一元素混用均可） -->
<button hx-ext="bny-attr"
    hx-target="#a, #b, all .item"
    attr-add="class:active">点亮</button>

<!-- find/closest 片段也可出现在逗号列表里 -->
<div hx-ext="bny-attr" hx-trigger="click"
    hx-target="find .tip, closest section, #other"
    attr-set="data-on:true">...</div>

表单控件属性

  • Preview
  • Code

复选框的 checked（以及 value / selected）存在浏览器 dirty 标志——用户手动点击/输入过之后，attribute 的变化不再反映到视觉（操作"看似失效"）。 bny-attr 写这些属性时自动同步 DOM property，先手动勾过任意一项再点全选/反选依然生效。

验证：先手动勾选任意一项，再点上方按钮——所有复选框仍正常切换。 

<!-- 典型场景：数据表格批量全选/反选（手动勾过某行也不失效） -->
<button hx-ext="bny-attr"
    hx-target="all #table-role input[name='id[]']"
    attr-toggle="checked">全选/反选</button>

<!-- 同理：attr-set="value:x" 对输入框、attr-set="selected" 对 option，
     写入后同步 DOM property，不受浏览器 dirty 标志影响 -->

根据返回 JSON 管理属性

  • Preview
  • Code

attr-json="data"：请求完成把响应 JSON（{…}）中 data 对象的键值写入目标。 元素自身带请求属性时响应完成后自动应用，无需声明触发事件； 配合 hx-swap="none" 不替换内容。卡片随 data-status 变色即为生效（online 变绿）。

此目标会获得响应 JSON 中的属性，并随 data-status 变绿

data-status：（未拉取） · data-users：- · data-zone：-

取 JSON 某个字段的值写入指定属性：attr-json="data.data-users" + attr-value="data-count"

目标将拥有 data-count = 响应 JSON 里 data.data-users 的值

data-count：-

条件触发：attr-json="data.data-users:1280" —— 只有该值等于 1280 才生效（变绿）；=999 不触发（不变）。

命中条件(data-users=1280) → 变绿
不满足条件(data-users=999) → 不变
<!-- attr-json：请求元素完成后自动应用，无需声明触发事件 -->
<div hx-ext="bny-attr" hx-get="/api/status"
    hx-trigger="load" hx-swap="none"          <!-- 不替换内容 -->
    attr-json="data"                            <!-- 响应 JSON 中要应用的路径 -->
    hx-target="#box">
  <button hx-trigger="click">再拉取</button>
  <div id="box">...</div>
</div>

<!-- 响应 JSON -->
{ "data": { "data-status": "online", "data-users": 1280 } }
<!-- → #box 获得 data-status="online"、data-users="1280" -->

<!-- 取单个字段值写入指定属性（attr-value） -->
<div hx-ext="bny-attr" hx-get="/api/status"
    hx-trigger="load" hx-swap="none"
    attr-json="data.data-users"   <!-- path 指向标量 -->
    attr-value="data-count"        <!-- 把该值写入 data-count -->
    hx-target="#box2"></div>

API

在元素上 hx-ext="bny-attr" 启用；attr-* 声明操作与配置。

属性说明
hx-target="选择器"目标元素，缺省为扩展元素自身；支持 htmx 选择器 find x / closest x；一对多：逗号分隔多目标、all x 批量选取；每次应用时实时解析，动态插入的目标也能找到（元素带请求属性时归 htmx 交换所有，须单个）
attr-set="k:v, k2:v2"整体设置/覆盖属性值（单值用）
attr-add="k:v"追加一个或多个值（空格分隔，不重复）
attr-remove="k"移除整个属性
attr-remove="k:v"仅移除该值（token 级）
attr-replace="k:old@new"多值属性把某个值替换为 new（空格分隔可多个）
attr-rename="old:new"改属性名（值保留）
attr-toggle="k:v"有则删、无则加（切换）
hx-trigger="事件[, 事件2]"触发事件，默认 click；逗号分隔可多个，每个取首个词为事件名；可填 htmx 事件名如 htmx:afterSwap；元素自身带请求属性时无需声明（响应完成后自动应用）
attr-auto初始化即应用一次（不做事件绑定）
attr-json="path"请求完成后从响应 JSON 取 path；对象则批量键值写入目标
attr-json="path:期望值"条件触发：仅当 path 取值等于期望才应用
attr-value="目标属性"配合 attr-json，把取到的字段值写入该目标属性

安全：写操作拒绝 on* 事件属性和 javascript:/vbscript: 危险值；应用后向目标派发 attr-applied 事件。
