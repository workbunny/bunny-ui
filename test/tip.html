气泡提示
v2.0.6+

气泡提示是一种悬浮提示组件，支持 12 方向自动定位，通过 tip 属性即可使用。

基础用法

  • Preview
  • Code
悬停我 
<button class="bny-btn" tip="这是一个基础提示">鼠标悬停</button>
<span tip="内联元素也支持">悬停我</span>

API

标签属性

属性 默认值 必须 描述 版本
tip — 否 气泡提示的纯文本内容（与 tip-html 二选一）
v2.0.5+
tip-html — 否 气泡提示的 HTML 内容（与 tip 二选一，优先级更高）
tip-delay 0 否 显示延迟时间（毫秒）
tip-placement — 否 手动指定方向，不设置则自动评分。可选值见下方定位表
tip-theme — 否 主题：light-亮色（白色背景+阴影）
tip-width 280px 否 自定义最大宽度

定位规则

方向 变体 描述
top top / top-start / top-end 上方居中 / 上方左对齐 / 上方右对齐
bottom bottom / bottom-start / bottom-end 下方居中 / 下方左对齐 / 下方右对齐
left left / left-start / left-end 左侧居中 / 左侧上对齐 / 左侧下对齐
right right / right-start / right-end 右侧居中 / 右侧上对齐 / 右侧下对齐
优先级：top → bottom → left → right。JS 引擎实时计算视口空间，自动选定最佳方向。
