Pagination 分页
v2.0.6+

分页组件，服务端返回 JSON 自动渲染分页条。与 htmx 集成，点击页码通过 hx-get 请求新数据。

基础用法

  • Preview
  • Code
点击页码按钮触发请求（这里返回静态 JSON 仅用于演示渲染）。 
<div hx-ext="bny-pagination"
     hx-get="/api/users"
     hx-target="#user-list"
     hx-swap="innerHTML"
     pg-max-buttons="7">
</div>
<div id="user-list"></div>

<!-- 服务端返回 JSON： -->
<!-- { "total": 100, "page": 1, "pageSize": 10 } -->

简洁模式 + 主题色

  • Preview
  • Code
<div hx-ext="bny-pagination"
     pg-color="blue" pg-model="simple"
     pg-max-buttons="5"
     pg-jumper="false"
     pg-total="false">
</div>

与表格组合

  • Preview
  • Code
pg-render-list="true" 配合 JSON 中的 columns 与 allList，自动渲染表格 + 分页条，点击页码切换数据（前端分页）。 
<div hx-ext="bny-pagination"
     hx-get="/api/users"
     hx-target="#table-demo"
     hx-swap="innerHTML"
     hx-trigger="load"
     pg-render-list="true"
     pg-page-size="5">
</div>
<div id="table-demo"></div>

<!-- 服务端返回 JSON： -->
<!-- { "total": 30, "pageSize": 5, -->
<!--   "columns": [{"field":"id","title":"ID"},...], -->
<!--   "allList": [{"id":1,...},...] } -->

配置项

  • Preview
  • Code
常用配置：
pg-max-buttons：最多页码按钮数（默认 7）
pg-page-size：每页条数（默认 10）
pg-jumper="false"：隐藏跳转框
pg-total="false"：隐藏总数
pg-page-param：URL 参数名（默认 page）
pg-color：主题色（default/green/blue/yellow/red）
pg-model="simple"：无边框简洁模式 
<div hx-ext="bny-pagination"
     hx-get="/api/list"
     hx-target="#demo"
     pg-page-size="20"
     pg-max-buttons="9"
     pg-page-param="p"
     pg-color="green">
</div>

API

属性

属性说明
hx-ext="bny-pagination"启用分页扩展
hx-get请求数据的 URL
hx-target列表/表格容器选择器
pg-max-buttons最多页码按钮数，默认 7
pg-page-size每页条数，默认 10
pg-page-paramURL 分页参数名，默认 page
pg-jumper设为 false 隐藏跳转框
pg-total设为 false 隐藏总数
pg-render-list设为 true 时按 JSON 的 columns / allList / list 自动渲染表格或列表
pg-color主题色：default/green/blue/yellow/red
pg-model设为 simple 无边框简洁模式

类名

类名说明
bny-pagination分页条容器（由扩展自动生成）
bny-pagination-total总数文本
bny-pagination-btn页码按钮，含 .active 当前页 / .disabled 禁用态
bny-pagination-prev / bny-pagination-next上一页 / 下一页
bny-pagination-ellipsis省略号
bny-pagination-jump跳转区域
bny-pagination-input跳转输入框
bny-pagination-list / bny-pagination-list-itemrender-list 时的简单列表
