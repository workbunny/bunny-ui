API

属性（静态标记）

以下属性作用于 bny-load / bny-load-ball / bny-load-health，均支持。

属性可选值说明
load-colorgreen / yellow / red / blue主题色变体（默认主色）
load-sizesmall / large尺寸变体（默认中号）

CSS 类名

类名说明
bny-load-shade全屏遮罩层，由 bny.load() 自动包裹生成
bny-load旋转加载器（圆形边框），支持 load-color / load-size
bny-load-ball弹跳点加载器，需 4 个 <div> 子元素（对应 4 个圆点），支持 load-color / load-size
bny-load-rot双球旋转加载器（纯 CSS，无子元素）
bny-load-health进度条式加载器，需 1 个 <div> 子元素（进度条），支持 load-color

JS 用法 bny.load(style, options)

参数默认值说明
style00-旋转(rot) / 1-圆形(load) / 2-弹跳(ball)；血条(health)仅静态标记，暂无对应 style 值
options.color—green / yellow / red / blue，映射为 load-color
options.size—small / large，映射为 load-size
