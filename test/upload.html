文件上传

基于 htmx 拓展 bny-upload 的文件上传组件：点击/拖拽选择文件、自动上传、进度反馈、前置校验、文件列表管理。

基础用法

  • Preview
  • Code
复用 htmx 原生请求：hx-post 决定上传地址。点击元素选择文件后自动上传，成功/失败由组件内置 bny.alert 提示。 
<div hx-ext="bny-upload" class="bny-upload" hx-post="/test/data/upload-response.json" upload-hint="点击选择文件后上传"></div>

多文件与校验

  • Preview
  • Code
upload-multi 多选；upload-ext 扩展名白名单；upload-size 单文件大小上限(KB)；upload-limit 数量上限。 
<div hx-ext="bny-upload" class="bny-upload" hx-post="/test/data/upload-response.json"
    upload-multi upload-accept="image/*" upload-ext="jpg,png,gif" upload-size="2048" upload-limit="5"
    upload-hint="点击选择文件后上传（可多选）"></div>

拖拽上传

  • Preview
  • Code
upload-drag 拖拽，upload-preview 图片缩略图。 
<div hx-ext="bny-upload" class="bny-upload" hx-post="/test/data/upload-response.json" upload-drag upload-multi upload-preview upload-hint="点击或拖拽文件到此处"></div>

按钮触发

  • Preview
  • Code
任意元素（按钮等）加 hx-ext="bny-upload" + hx-post 即成为触发点。upload-list 控制列表渲染：缺省不渲染，写选择器则渲染到指定元素（"this"=元素自身）。 
    <button class="bny-btn" hx-ext="bny-upload"
        hx-post="/test/data/upload-response.json" hx-trigger="click"
        upload-multi upload-list="#upload-list"><i class="bny-icon icon-folder-add"></i> 选择文件上传</button>

<ul id="upload-list"></ul>

    API

    标签属性

    属性 默认值 必须 描述 版本
    hx-ext bny-upload 是 拓展属性名
    hx-post / hx-put / hx-patch / hx-delete / hx-get - 是 上传接口（htmx 原生请求属性，任选其一；实际携带文件请用可带 body 的动词）。组件自动把隐藏 file input 挂进请求（hx-include），并强制 hx-swap="none" 防止响应 JSON 覆盖元素
    hx-trigger click 否 触发方式（htmx 原生）
    upload-name file 否 上传字段名（file input 的 name）
    upload-accept * 否 允许的 MIME 类型(可逗号分隔, 支持 image/* 通配)
    upload-ext 空 否 扩展名白名单(逗号分隔, 如 jpg,png,gif)
    upload-limit 0 否 文件数量上限(0=不限)
    upload-size 0 否 单文件大小上限(单位 KB, 0=不限)
    upload-multi 无 否 存在即支持多选
    upload-hint 点击选择文件后上传 否 元素为空时的提示文案：未配置 upload-list 时显示在框内；upload-list="this" 时为空列表提示（缺省"点击选择文件后上传"）
    upload-preview 无 否 存在则成功上传的图片显示缩略图并可放大预览
    upload-drag 无 否 存在则启用拖拽上传
    upload-list 空 否 列表渲染目标：缺省不渲染；"this"=元素自身内；CSS 选择器（#id/.cls/find x/closest x）=渲染到指定元素

    响应格式

    上传接口应返回 JSON：{code:0,msg:"...",url:"..."}。code=0 判为成功（列表项绿色"上传成功"，url 供 upload-preview 缩略图）；code!=0 判为失败（列表项红色"上传失败"）。msg 由组件内置 bny.alert 弹出。

    组件行为

    bny-upload

    • 复用 htmx 请求管线：选中文件后组件用 htmx.ajax 发起请求（multipart/form-data），上传进度经 htmx:xhr:progress 实时驱动列表进度条（"上传中 N%"）。
    • 校验失败（upload-ext / upload-size / upload-accept / upload-limit）直接 bny.alert 拦截，不发请求。
    • 响应 code=0/非 0 判定成功/失败；msg 内置 bny.alert 提示，无需再挂 bny-alert。
    • hx-swap 由组件强制为 none（除非已显式设置），响应不会覆盖触发器/容器，可连续多次上传。
    • 上传成功后重置文件选择，可重复选择同一文件。
    • 失败项显示"重新上传"（点击重发该文件并恢复列表态）；成功项显示删除"×"（移除列表项并释放 upload-limit 配额）。
