Rate 评分
v2.0.6+

评分组件，鼠标 hover 预览、click 选中、键盘方向键调整。支持半星、只读、主题色与文本提示。

基础用法

  • Preview
  • Code
鼠标移入星星预览，点击选中。 
<div class="bny-rate" rate-value="3"></div>

半星 + 文本

  • Preview
  • Code
<div class="bny-rate"
     rate-value="3.5"
     rate-half
     rate-show-text>
</div>

只读 + 主题色

  • Preview
  • Code
<div class="bny-rate" rate-value="4"
     rate-readonly rate-color="blue">
</div>

配合 HTMX

  • Preview
  • Code
选值后会派发 change 事件，配合 hx-trigger="change" 即可提交到服务端。 
<div class="bny-rate"
     rate-value="0"
     hx-post="/api/rate"
     hx-trigger="change"
     hx-vals='{\"id\": 123}'>
</div>

API

属性

属性说明
rate-value当前分值，支持小数
rate-max最大星数，默认 5
rate-half启用半星
rate-readonly只读模式
rate-show-text显示文本提示
rate-texts文本数组，逗号分隔（如 很差,失望,一般,满意,惊喜）
rate-color主题色：default/green/blue/yellow/red
rate-size尺寸变体：sm / lg

类名

类名说明
bny-rate评分容器（自动初始化）
bny-rate-stars星星列表容器
bny-rate-star单个星星
bny-rate-icon星星 SVG，含 .is-active / .is-half 状态
bny-rate-text文本提示（rate-show-text 时生成）
.is-readonly只读态，禁止交互
