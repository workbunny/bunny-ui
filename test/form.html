表单校验

基于 htmx 事件链的表单校验：在 <form hx-ext="bny-form"> 上启用，支持 HTML5 原生约束（required/pattern/minlength 等）和自定义 valid-rules，校验失败阻止请求并显示错误提示。

基础用法

  • Preview
  • Code
点击提交触发校验：错误字段标红、显示提示、阻止表单提交。修正后实时清除错误。 
<form hx-ext="bny-form" style="max-width:420px;">
    <div class="form-item">
        <label>用户名</label>
        <input class="bny-input" name="user" required
               valid-msg-required="请输入用户名">
    </div>
    <div class="form-item">
        <label>邮箱</label>
        <input class="bny-input" type="email" name="email" required
               valid-msg-required="邮箱必填"
               valid-msg-type="邮箱格式不正确">
    </div>
    <div class="form-item">
        <label>密码</label>
        <input class="bny-input" type="password" name="pwd"
               required minlength="6"
               valid-msg-min="密码至少 6 位">
    </div>
    <div class="form-item">
        <label>确认密码</label>
        <input class="bny-input" type="password" name="pwd2"
               valid-rules="equals:pwd"
               valid-msg-equals="两次密码不一致">
    </div>
    <button class="bny-btn" type="submit">提交</button>
</form>

自定义规则 valid-rules

  • Preview
  • Code
<!-- 长度规则 -->
<input required valid-rules="min:3,max:20">

<!-- 数值范围 -->
<input type="number" required valid-rules="min-val:18,max-val:99">

<!-- 正则 -->
<input required valid-rules="regexp:^1[3-9]\d{9}$">

配合 bny-alert 弹窗提示

在 <form hx-ext="bny-form"> 上加 valid-alert 属性，校验失败时除行内红字外，会自动调用 bny.alert() 弹出第一条错误；校验通过时弹“校验通过”。与 bny-alert 组件零耦合组合，不加属性则完全不弹窗。
  • Preview
  • Code
留空或填错后点提交：顶部弹出红色 alert 显示第一条错误，同时字段标红。全部填对后点提交：弹出绿色“校验通过”。 
<form hx-ext="bny-form" valid-alert style="max-width:420px;">
    <div class="form-item">
        <label>用户名</label>
        <input class="bny-input" name="user" required
               valid-rules="min:3,max:20"
               valid-msg-required="请输入用户名"
               valid-msg-min="不能少于 3 字符"
               valid-msg-max="不能超过 20 字符">
    </div>
    <div class="form-item">
        <label>邮箱</label>
        <input class="bny-input" type="email" name="email" required
               valid-msg-required="请输入邮箱"
               valid-msg-type="邮箱格式不正确">
    </div>
    <button class="bny-btn" type="submit">提交</button>
</form>

校验属性 API

属性说明
hx-ext="bny-form"在 <form> 上启用表单组件（布局 + 校验）
requiredHTML5 原生必填，空值触发 valid-msg-required
valid-msg-required必填（valueMissing）错误消息
valid-msg-type类型不匹配（typeMismatch，如 email）错误消息
valid-msg-pattern正则不匹配（patternMismatch / 自定义 regexp 规则）错误消息
valid-msg-min最短长度（tooShort / min / min-val 规则）错误消息
valid-msg-max最长长度（tooLong / max / max-val 规则）错误消息
valid-msg-equalsequals 规则（两字段相等）错误消息
valid-msg通用兜底消息，任意校验失败且未配置对应专用消息时使用
valid-rules自定义规则，逗号分隔，如 min:3,max:20,min-val:18,max-val:99,regexp:^1[3-9]\d{9}$,equals:pwd
valid-alert表单级开关：开启后校验失败自动 bny.alert() 弹第一条错误（code 3 红），校验通过弹“校验通过”（code 1 绿）；不开启则完全不弹窗

API

属性（表单控件）

属性可选值说明
form-sizesm / lg尺寸变体，作用于 bny-input / bny-textarea / bny-select / bny-input-group（默认 38px，sm=30px，lg=46px）
data-disabledtrue仅作用于 bny-input-group，整体置灰禁用；也可由内部 input 的 disabled 自动触发

CSS 类名

类名说明
bny-input输入框，支持 placeholder / disabled / focus
bny-textarea多行文本框，可拖动调整高度
bny-select下拉选择框，带自定义箭头
bny-radio单选框，支持 checked / disabled
bny-checkbox复选框，支持 checked / disabled
bny-switch开关，滑动切换，支持 checked / disabled
bny-slider滑块，自定义 thumb 样式
bny-input-group输入框组合容器（前缀/后缀），内部 input 去边框、由容器统管圆角与焦点
bny-input-prefix / bny-input-suffix组合的前缀/后缀插槽，可放文本、图标（bny-icon）或按钮（bny-btn）
form-item表单项容器（配合 hx-ext="bny-form"），统一 label + 控件间距
input-group表单项内的控件行，支持多控件横向排列（如 input + 按钮）
bny-input-error校验失败态类，加在 input/textarea/select 上，边框变红
bny-form-error校验错误提示文本元素，由 bny-form 自动注入到 .form-item 末尾
is-valid（可选）加在 .form-item 上，使内部控件边框变绿，标记校验通过

扩展（hx-ext）

扩展名说明
bny-form表单组件（布局 + 校验）：在 <form hx-ext="bny-form"> 上启用，配合 form-item / input-group 实现统一排版；同时接管原生校验，支持 HTML5 约束与 valid-rules / valid-msg 自定义规则，失败时加 bny-input-error 并显示 bny-form-error
