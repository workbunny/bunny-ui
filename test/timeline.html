Timeline 时间线
v2.0.6+

API

CSS 类

类名/属性说明
bny-timeline时间线容器
mode="right"右侧布局
mode="alternate"交错布局
color="green/blue/yellow/red"主题色变体
bny-timeline-item时间线项
bny-timeline-node节点圆点
bny-timestamp时间戳
bny-timeline-title标题
bny-timeline-content内容
is-primary/success/warning/danger/info节点状态色
is-hollow空心节点
