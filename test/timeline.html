API

Timeline 属性

属性 可选值 说明
tl-mode right / alternate 布局方向；默认 left（主轴在左），可选 right（主轴在右）、alternate（左右交错）
tl-color green / blue / yellow / red 统一节点主题色（作用于所有节点圆点）

Timeline 类名

类名 说明
bny-timeline时间线容器
bny-timeline-item时间线项
bny-timeline-node节点圆点
bny-timestamp时间戳
bny-timeline-title标题
bny-timeline-content内容
is-primary / is-success / is-warning / is-danger / is-info节点状态色（单个 item 上的修饰类）
is-hollow空心节点（仅边框，无填充）
has-icon节点内放自定义图标（放大节点并居中图标）
