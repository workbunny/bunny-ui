API

CSS 类

类名说明
bny-blockquote引用块，左侧粗边框，支持 sub-color 属性
bny-fieldset字段集容器，带圆角和 legend
bny-fieldset-title无边框字段集，仅保留顶部横线 + legend
hr全局分割线，支持 sub-color 属性
