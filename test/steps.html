Steps 步骤条
v2.0.6+

步骤引导组件，纯 CSS 实现。支持横向/纵向、4 种状态（wait/process/finish/error）、主题色与简洁模式。

API

Steps 属性

属性 可选值 说明
step-direction vertical 布局方向；默认 horizontal（横向），可选 vertical（纵向）
step-model simple 简洁模式（缩小图标尺寸）
step-color green / blue / red 主题色变体（作用于进行中/完成态与连接线）

Steps 类名

类名 说明
bny-steps步骤条容器
bny-step单个步骤项
bny-step-head头部（图标 + 标题/描述容器）
bny-step-icon步骤图标圆点
bny-step-num序号文字（完成/错误态自动隐藏）
bny-step-content内容容器
bny-step-title标题
bny-step-desc描述
is-wait等待状态（灰色）
is-process进行中状态（主色实心 + 光环）
is-finish完成状态（主色 + 对勾）
is-error错误状态（红色 + ×）
bny-steps-clickable可点击（hover 放大图标）
