自定义排序值

  • Preview
  • Code

当单元格显示内容与排序值不一致时，使用 table-sort-val 指定参与排序的值

排名 选手
🥇 第一名 选手A
🥉 第三名 选手C
🥈 第二名 选手B 
<table hx-ext="bny-table">
    <thead>
        <tr>
            <th table-sort="number">排名</th>
            <th>选手</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td table-sort-val="1">🥇 第一名</td>
            <td>选手A</td>
        </tr>
        <tr>
            <td table-sort-val="2">🥈 第二名</td>
            <td>选手B</td>
        </tr>
        <tr>
            <td table-sort-val="3">🥉 第三名</td>
            <td>选手C</td>
        </tr>
    </tbody>
</table>

富内容单元格 + 持久化排序

  • Preview
  • Code
  • Json
单元格支持 { "__html": "..." } 渲染原始 HTML（用于链接/按钮等富内容）。点击列头排序后，HTMX 重新加载会从 sessionStorage 恢复排序状态。 
<button hx-ext="bny-table" hx-get="/test/data/table03.json"
    hx-target="#table-raw-demo" hx-swap="innerHTML">加载表格</button>

// 单元格使用对象 { __html: '<a ...>编辑</a>' } 时会渲染原始 HTML
            
// table03.json
{
    "key": "user-list",
    "cols": [
        {"name": "姓名", "sortable": true, "sort": "string"},
        {"name": "操作", "sortable": false}
    ],
    "rows": [
        ["张三", {"__html": "<a class='bny-btn' model='border'>编辑</a>"}]
    ]
}

API

标签属性

属性 默认值 必须 描述 版本
hx-ext bny-table 是 拓展属性名
table-color default 否 表头颜色：green/yellow/red/blue
table-sort string 否 作用于 th，启用排序。值 number 表示按数字排序，默认为字符串
table-sort-val — 否 作用于 td，指定该单元格参与排序的值（显示与排序值不同时使用）

JSON属性

属性 默认值 必须 描述 版本
tab — 否 表头颜色：green/yellow/red/blue
cols [] 是 列名字符串数组
rows [] 是 二维数组，每行为一条数据

排序行为

  1. 点击带 table-sort 属性的表头即可排序
  2. 首次点击 → 升序（▲ 高亮），再次点击 → 降序（▼ 高亮）
  3. table-sort="number" 按数值排序，否则按字符串排序
  4. 单元格可通过 table-sort-val 指定参与排序的实际值
  5. JSON 响应自动渲染为完整表格，同时支持直接追加 HTML 行
