表格

表格是一种用于展示数据的结构化布局，两种用法开箱即用：<table hx-ext="bny-table"> 静态表格（手写 HTML，表头排序、移动端响应式卡片）； 加 table-static 即为数据表格——静态表头声明列模型（cell-* + cell-template 模板）， hx-get 请求服务端分页 JSON 自动渲染行，内置分页条、服务端排序、树形嵌套、长文本省略与放大镜、加载骨架屏与渐显动画。

数据表格（table-static 基础）

  • Preview
  • Code
  • Json

表头写好即列模型，hx-get 请求服务端分页 JSON 自动渲染 tbody； 带 cell-sort 的列点击表头排序（发 sort/order 参数）， 响应含 total 时表格下方自动渲染内置分页条。

ID 姓名 角色 邮箱 注册时间 
<table hx-ext="bny-table" table-static table-server table-key="basic-users"
       hx-get="/test/data/table-static.json" hx-trigger="load"
       hx-target="find tbody" hx-swap="innerHTML">
    <thead><tr>
        <th cell-field="id" cell-align="center">ID</th>
        <th cell-field="name" cell-sort>姓名</th>
        <th cell-field="role">角色</th>
        <th cell-field="email">邮箱</th>
        <th cell-field="reg_time" cell-sort>注册时间</th>
    </tr></thead>
    <tbody></tbody>
</table>

// table-static：启用"静态表头 + 服务端数据"模式，tbody 由响应数据渲染
// hx-trigger="load"：页面加载即请求；也可改为按需触发（按钮/搜索输入等）
// hx-target="find tbody"：JSON 渲染出的行填入表内 tbody
// table-server：翻页/排序由服务端完成，组件只发参数（默认 page/pageSize/sort/order）
// table-key：同页多个数据表格各配唯一 key（排序状态存 sessionStorage，互不干扰）
// table-list：内置分页条的条数选项（逗号分隔，如 "10,20,50"），首项为默认每页条数
                
// /test/data/table-static.json — 服务端分页契约（ThinkPHP / Laravel paginate() 原生格式）
{
    "total": 14,              // 总记录数（存在时自动渲染分页条）
    "per_page": 5,            // 每页记录数
    "current_page": 1,        // 当前页码
    "last_page": 3,           // 总页数
    "has_more": true,
    "data": [                 // 当前页行对象（兼容 data / list / rows 键名）
        {"id": "1", "name": "张伟", "role": "管理员", "status": "1",
         "email": "zhangwei@test.com", "reg_time": "2024-03-12"},
        ...
    ]
}

// data 为空数组时渲染占位行（文案取 empty 字段，缺省"暂无数据"）

列模型写在静态表头（cell-* 声明），服务端只回当前页数据 + 总条数； 富内容用 cell-template="#id" / ".class" 选择器引用 <template> 模板元素， {{data.field}} 字段直取（点路径，值转义），也支持 {{data.status == 1 ? '正常' : '禁用'}} 三元等表达式（data 即行对象，结果同样转义），模板是独立 HTML 块—— 标签（bny-tag）、链接、按钮（bny-btn）皆由模板生成。 点击表头排序（服务端模式发 sort/order 参数），表格下方自动渲染内置分页条。

ID 姓名 邮箱 备注（长文本）
长文本省略：桌面端非模板列默认单行省略，行高不因长文本撑高；内容真实溢出的单元格右侧出现放大镜图标（未溢出不渲染）。
查看完整内容：悬停溢出单元格由 tip 组件提示"点击展开"；点击放大镜固定弹出完整内容，鼠标可移入气泡框选复制； 放大镜按钮在链接外，查看内容不会触发链接跳转。再点一次放大镜 / 点击空白处 / 滚动表格即收回。
省略开关：列声明 cell-ellipsis="false" 关闭省略（恢复换行），cell-ellipsis="true" 对模板列强制开启（模板列默认不省略）；移动端卡片布局不做截断、不渲染放大镜。
加载骨架屏与渐显：加载/重载超过 200ms 未返回时，tbody 自动渲染表格形骨架（表头条 + 行条，复用骨架屏组件流光，行数取 table-list 首项，介于 3~10）；数据到位后骨架随内容交换被替换，表格与内置分页条同拍渐显（0.35s）； 快响应不显示骨架不闪烁，请求失败自动清理。本地静态 JSON 响应极快，可用浏览器 DevTools 网络限速体验完整流程。

静态表头 + 服务端数据

真实后台架构：列模型（表头）写在页面静态 HTML 里，服务端只返回当前页数据 + 总条数。 分页 / 排序 / 筛选全部由后台 SQL 完成，前端只发参数——数据量大的生产场景用这个模式， 不再要求后台一次性返回全量数据。

API

标签属性

属性 默认值 必须 描述 版本
hx-ext bny-table 是 拓展属性名
table-color default 否 表头颜色：green/yellow/red/blue
table-static — 否 静态表头模式：表头写在页面 HTML，行由响应 JSON 渲染 v2.3.1+
table-server — 否 服务端模式：排序 / 翻页发请求参数，由后台计算返回 v2.3.1+
table-key — 否 表格唯一标识：本地排序时记忆排序状态（sessionStorage），刷新自动回显 v2.3.1+
table-list 10 否 每页条数选项，逗号分隔（如 10,20,50），首项为默认值；缺省 10 v2.3.1+
table-sort-param / table-order-param / table-page-param sort / order / page 否 服务端排序的三个请求参数名，可按后台约定定制 v2.3.1+
pg-* — 否 分页条配置（pg-page-size、pg-jumper 等），详见分页组件 v2.3.1+

响应契约（paginate JSON）

table-static 模式下接口返回标准分页结构（ThinkPHP / Laravel paginate() 原生格式），行对象按 th 的 cell-field 取值渲染：

字段 必须 描述
data 是 当前页行对象数组；兼容 list / rows 键名；行对象可带 children 数组嵌套子行（树形表格）
total 否 总条数；存在时自动渲染分页条
per_page / current_page / last_page / has_more 配合 total 每页条数 / 当前页码 / 总页数 / 是否还有下一页（分页计算依据）
empty 否 data 为空时的占位文案，缺省"暂无数据"

列声明（th 的 cell-* 属性）

属性描述
cell-field行对象取值字段（模板列可不声明）
cell-align列对齐：left / center / right
cell-ellipsis单行省略：非模板列默认开启；false 关闭，true 对模板列强制开启；仅桌面端生效
cell-template<template> 模板选择器（#id / .class 等，以 # / . 开头即按选择器引用，否则为内联模板串）：模板内 {{data.字段}} 字段直取（点路径），也支持 {{表达式}}——data 即行对象，三元 / 比较 / 逻辑等 JS 表达式（求值失败保留原文并告警），结果自动转义，可含 HTML（按钮 / 标签 / 链接）
cell-sort启用列排序：值 number 按数值排序，缺省按字符串排序（旧写法 table-sort 兼容）
cell-sort-val排序取值字段——显示文案与排序值不同时使用（如标签列按底层值排序）

操作按钮（data-bny-action）

操作列由 cell-template 模板渲染按钮，按钮加 data-bny-action 即接入统一协议（dropdown 菜单内同样生效，点击自动收起面板）：

属性描述
data-confirm先弹确认框，确认后继续
data-event派发自定义事件（detail 为 {row, page}），由业务处理
data-url / data-method / data-targethtmx.ajax 发请求；method 缺省 GET，target 缺省刷回表格容器
data-row按钮携带的行数据 JSON，由模板插值生成：data-row='{"id":{{data.id}},"name":"{{data.name}}"}'
安全约定：{{data.field}} 插值一律转义，模板 HTML 与 htmx 直接 swap 同级信任——仅用于受信任的服务端内容。

排序行为

  1. 点击带 cell-sort 的标题循环：升序（▲）→ 降序（▼）→ 还原
  2. cell-sort="number" 按数值排序，缺省按字符串；cell-sort-val 指定排序取值字段（显示与排序值不同时）
  3. table-server 模式排序发请求：带 sort / order 参数并回第 1 页，箭头状态由响应 URL 回显
  4. 本地排序模式声明 table-key 时，排序状态记忆到 sessionStorage，刷新自动回显
  5. 树形表格自动禁用排序（行序即层级从属）

交互与加载行为

  1. 桌面端非模板列默认单行省略；cell-ellipsis="false" 关闭（恢复换行）、cell-ellipsis="true" 对模板列强制开启；移动端卡片布局不截断
  2. 内容真实溢出的单元格右侧渲染放大镜图标（未溢出不渲染；图标字体就绪与窗口尺寸变化自动校准）
  3. 悬停溢出单元格：tip 组件提示"点击展开"；点击放大镜：固定弹出完整内容（可框选复制、不触发链接跳转）；再点一次 / 点击空白处 / 滚动表格收回
  4. 加载/重载超过 200ms 未返回：目标容器自动渲染表格骨架屏（行数取 table-list 首项，介于 3~10）；数据到位后表格与内置分页条渐显；请求失败自动清理骨架
