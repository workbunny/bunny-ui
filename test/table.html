表格

表格是一种用于展示数据的结构化布局，两种用法开箱即用：<table hx-ext="bny-table"> 静态表格（表头排序、移动端响应式卡片）； 数据表格（hx-get 请求 JSON）自动渲染，支持列模型富内容（标签/链接/头像/操作按钮组）、内置分页与搜索过滤、 长文本省略与放大镜查看、加载骨架屏与渐显动画。

静态表格（<table hx-ext="bny-table"> 手写 HTML）开箱获得表头排序与移动端响应式能力； 数据表格（hx-get 请求 JSON 自动渲染）在此基础上增加列模型富内容、内置分页、搜索过滤、长文本省略与加载骨架屏，见下文各章节。
移动端（< 768px）自动切换卡片式布局：隐藏表头，每行渲染为"字段名 + 值"卡片（字段名取自表头 th），内容不再受列宽限制，可完整换行展示。

长文本省略与加载动画

  • Preview
  • Code
  • Json
长文本省略：桌面端文本/链接列默认单行省略，行高不因长文本撑高；内容真实溢出的单元格右侧出现放大镜图标（未溢出不渲染）。
查看完整内容：悬停溢出单元格由 tip 组件提示"点击展开"；点击放大镜固定弹出完整内容，鼠标可移入气泡框选复制； 放大镜按钮在链接外，查看内容不会触发链接跳转。再点一次放大镜 / 点击空白处 / 滚动表格即收回。
省略开关：列配置 ellipsis: false 关闭省略（恢复换行），ellipsis: true 对 template 等列强制开启；移动端卡片布局不做截断、不渲染放大镜。
加载骨架屏与渐显：加载/重载超过 200ms 未返回时，目标容器自动渲染表格形骨架（表头条 + 行条，复用骨架屏组件流光，行数取 table-page-size/pg-page-size，介于 3~10）；数据到位后骨架随内容交换被替换，表格与内置分页条同拍渐显（0.35s）； 快响应不显示骨架不闪烁，请求失败自动清理。可用浏览器 DevTools 网络限速体验完整流程。

多条件搜索

多条件搜索：条件控件放同一容器，hx-include="closest div" 让任一控件触发时带上全部条件（AND 组合）； 表格 table-filter 声明可过滤字段（URL 同名参数本地过滤，allList 模式，total 同步）； 翻页/切条数自动保持当前条件。 
<!-- 多条件搜索：条件控件同一容器，hx-include 让任一控件带上全部条件 -->
<div style="display:flex;gap:8px">
    <input name="name" hx-ext="bny-table" hx-get="/api/list"
        hx-target="#demo" hx-trigger="input changed delay:400ms, search"
        hx-include="closest div">
    <select name="status" hx-ext="bny-table" hx-get="/api/list"
        hx-target="#demo" hx-trigger="change" hx-include="closest div">
</div>
<div hx-ext="bny-table" hx-get="/api/list" hx-target="#demo" hx-trigger="load"
     table-filter="name,email,status"></div>
<div id="demo"></div>

API

标签属性

属性 默认值 必须 描述 版本
hx-ext bny-table 是 拓展属性名
table-color default 否 表头颜色：green/yellow/red/blue
table-sort string 否 作用于 th，启用排序。值 number 表示按数字排序，默认为字符串
table-sort-val — 否 作用于 td，指定该单元格参与排序的值（显示与排序值不同时使用）
table-page-size / table-page-param 10 / page 否 allList 前端分页切片的每页条数与 URL 分页参数名 v2.3.0
pg-* — 否 内置分页条配置（JSON 带 total 时生效）：pg-page-size、pg-page-sizes（条数选择列表，如 "10,20,50"）、pg-size-param、pg-max-buttons、pg-page-param、pg-jumper="false"、pg-total="false"、pg-color、pg-model，详见分页组件 v2.3.0

JSON属性

属性 默认值 必须 描述 版本
color — 否 表头颜色：green/yellow/red/blue
key — 否 表格唯一标识，用于排序状态持久化（sessionStorage）
empty 暂无数据 否 空数据占位文案
cols / columns [] 是 列定义：字符串或对象（name/title、sortable、sort、field、type、align、width 等，见下方"单元格类型"） columns 为 v2.3.0 新增
rows [] 否 位置行：二维数组；支持树形行 {cells, children} 与 {__html} 原始行
list / allList [] 否 对象行：配合 columns 按 field 取值，支持全部列类型；allList 为全量数据自动按 page/pageSize 前端分页切片 v2.3.0
total — 否 内置分页：带 total 时表格后自动渲染分页条（pg-* 属性配置样式与行为，见分页组件文档） v2.3.0
table-filter — 否 本地过滤（仅 allList 模式）：逗号分隔的可过滤字段列表，请求 URL 里同名非空参数作为条件（AND 组合、包含匹配），total 同步过滤后条数 v2.3.0
pageSize / page 10 / 1 否 allList 前端分页：每页条数与当前页（page 优先取请求 URL 的 page 参数）；元素属性 table-page-size / table-page-param 可覆盖 v2.3.0

单元格类型（columns 的 type）

type渲染为列配置
text（默认）纯文本（一律转义）ellipsis: false 关闭单行省略（默认开启，行高统一；溢出单元格悬停由 tip 组件提示"点击展开"，点击右侧放大镜查看完整内容，不触发链接跳转；移动端不截断）
tagbny-tag 标签map：值 → 颜色（"red"）或 {text, color}；default 键兜底
link<a> 链接href（{field} 占位，值 URL 编码）、text、target
image图片/头像src（{field} 占位）、width、height、round
actions操作按钮（bny-btn，group: true 时为 bny-btn-group 按钮组）actions[]：text/icon/color/model/size/title/confirm/url/method/target/event；带 children[] 的项渲染为"更多"垂直菜单（菜单组件白主题），收纳次要操作（子项配置同主按钮）
template自定义模板template：{field} 占位符替换为转义后的行数据，模板本身可含 HTML
任意 + html: true原样 HTML列级逃生门；cell 级用 {__html}（rows 位置行同样支持）。仅限受信任的服务端内容
所有列均支持 title/name、width、align（left/center/right）、sortable/sort（列排序）、sortVal（排序取值字段）、ellipsis（单行省略：文本/链接列默认开启，false 关闭，true 强制开启；仅桌面端生效）。
actions 动作：confirm 先弹确认框；url（配 method/target）发请求，无 target 默认刷回表格容器； event 派发自定义事件（detail: {row, page}）交由业务处理。
安全约定：行数据一律转义/URL 编码；actions 按钮仅输出白名单属性（拒绝 on* 注入）；链接协议拒绝 javascript:/data:/vbscript:。

排序行为

  1. 点击带 table-sort 属性的表头即可排序
  2. 首次点击 → 升序（▲ 高亮），再次点击 → 降序（▼ 高亮）
  3. table-sort="number" 按数值排序，否则按字符串排序
  4. 单元格可通过 table-sort-val 指定参与排序的实际值
  5. JSON 响应自动渲染为完整表格，同时支持直接追加 HTML 行
  6. JSON 列模型（columns）里用 sortable / sort 声明列排序（v2.3.0），对象行同样生效
  7. 列配置 sortVal 指定排序取值字段（v2.3.0）——显示文案与排序值不同时使用（如 tag 映射列按底层值排序）
  8. 树形表格自动禁用排序（行序即层级从属，排序会打乱父子结构）

交互与加载行为

  1. 桌面端文本/链接列默认单行省略；ellipsis: false 关闭（恢复换行）、ellipsis: true 对 template 等列强制开启；移动端卡片布局不截断
  2. 内容真实溢出的单元格右侧渲染放大镜图标（未溢出不渲染；图标字体就绪与窗口尺寸变化自动校准）
  3. 悬停溢出单元格：tip 组件提示"点击展开"；点击放大镜：固定弹出完整内容（可框选复制、不触发链接跳转）；再点一次 / 点击空白处 / 滚动表格收回
  4. 加载/重载超过 200ms 未返回：目标容器自动渲染表格骨架屏（行数取 table-page-size / pg-page-size，介于 3~10）；数据到位后表格与内置分页条渐显；请求失败自动清理骨架
  5. "更多"弹出菜单复用菜单组件垂直菜单观感（白主题，暗色模式自动适配），菜单项走 actions 同一协议（confirm/url/event）
