Image 图片预览
v2.0.7+

图片预览组件，给 img 加 data-preview 即可启用点击放大预览。支持分组翻页、滚轮/按钮缩放、旋转、键盘操作。

基础用法

  • Preview
  • Code
点击图片打开全屏预览。 
<img src="thumb.jpg" data-preview>

分组预览

  • Preview
  • Code
同一 data-preview-group 内的图片可翻页查看。 
<img src="a.jpg" data-preview data-preview-group="gallery">
<img src="b.jpg" data-preview data-preview-group="gallery">
<img src="c.jpg" data-preview data-preview-group="gallery">

指定大图地址

  • Preview
  • Code
缩略图与大图地址不同时，用 data-preview-src 指定大图。 
<img src="thumb.jpg"
     data-preview
     data-preview-src="full.jpg">

操作说明

  • Preview
  • Code
预览打开后可用操作：
  • ← / →：上一张 / 下一张
  • + / -：放大 / 缩小
  • 0：重置缩放
  • ESC：关闭
  • 鼠标滚轮：缩放
  • 鼠标拖拽：平移
// 键盘 / 鼠标操作无需额外配置

API

属性

属性说明
data-preview启用预览
data-preview-src大图地址（默认取 src）
data-preview-group分组名，同组可翻页（旧版全局分组）
.bny-image-group图片分组容器，包裹多个 <img data-preview> 即形成重叠分组，点击任一张在灯箱内翻页
data-preview-size分组容器缩略图尺寸(px)，默认 56
data-preview-tags左上角标签，逗号分隔；text:color 指定颜色（green/blue/yellow/red），如 "封面:green,实拍"；堆叠中每张图各自显示，灯箱内随当前图切换

图片堆叠分组（手写容器）
v2.0.9+

  • Preview
  • Code
用 .bny-image-group 包裹多张 <img data-preview> 即为重叠分组， 点击任一张在灯箱内翻页浏览整组。data-preview-size 调整缩略图尺寸（默认 56px）。 
<div class="bny-image-group" data-preview-size="72">
  <img src="a.jpg" data-preview data-preview-src="a-full.jpg">
  <img src="b.jpg" data-preview data-preview-src="b-full.jpg">
  <img src="c.jpg" data-preview data-preview-src="c-full.jpg">
</div>

Markdown 自动成组
v2.0.9+

  • Preview（渲染效果）
  • Code（Markdown 源）
在 Markdown 中连续写多张图片，渲染时会自动包成 .bny-image-group（需引入 ext/markdown/markdown.js）。 
![图1](ma.jpg) ![图2](mb.jpg) ![图3](mc.jpg)

图片标签
v2.0.9+

  • Preview
  • Code
每张图用 data-preview-tags="标签1:颜色,标签2" 声明左上角小标签（逗号分隔，text:color 指定颜色，可选 green/blue/yellow/red）。 堆叠中每张卡片显示各自的标签；点击打开灯箱翻页时，大图左上角浮层显示当前图标签。 
<!-- 堆叠分组：每张卡片各自标签 -->
<div class="bny-image-group" data-preview-size="72">
  <img src="a.jpg" data-preview data-preview-src="a-full.jpg"
       data-preview-tags="封面:green,实拍">
  <img src="b.jpg" data-preview data-preview-src="b-full.jpg"
       data-preview-tags="风景:blue">
</div>

<!-- 单图标签 -->
<img src="x.jpg" data-preview data-preview-src="x-full.jpg"
     data-preview-tags="封面:green">
