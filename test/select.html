选择框

基于 htmx 拓展 bny-select 的多功能选择框：单选、多选、树形单选、树形多选（父子联动）、禁用。 推荐 <ul hx-ext="bny-select"> 直接承载（ul 本身变身组件，子 li 即选项）； 也支持原生 select 渐进增强或 hx-get 拉取服务端数据（HTML 片段 / JSON 自动识别）； 值写入视觉隐藏的值域元素（多选逗号合并，如 tags=1,2,3）， 与 bny-form 校验、htmx 表单序列化零改动协作。

树形单选

  • Preview
  • Code

select-tree 开启树形：选项用 option-parent 引用父级的 option-value 表达层级，缩进与折叠箭头由组件注入 （服务端片段无需关心顺序与缩进），点箭头折叠/展开后代，任意层级均可选择。

    值域：（空）

    <ul hx-ext="bny-select" select-name="dept" select-tree
    select-placeholder="请选择部门"
    hx-get="/test/data/select-tree.html"></ul>

<!-- 服务端片段：option-parent 引用父级 option-value（顺序无关，按引用还原树形） -->
<li option-value="10">总部</li>
<li option-value="11" option-parent="10">研发中心</li>
<li option-value="12" option-parent="11">前端组</li>

[
  "北京",
  {"value": "2", "label": "上海"},
  {"label": "华东", "children": [
    {"value": "3", "label": "杭州"},
    {"value": "4", "label": "苏州", "disabled": true}
  ]},
  {"value": "5", "label": "广东省", "children": [
    {"value": "6", "label": "深圳"}
  ]}

          API

          属性（声明在扩展元素上） 说明
          select-name="字段名" 必填（原生 select 承载时改用原生 name）：值域字段名，多选逗号合并提交
          select-value="1,3" 初始值，逗号分隔；优先级高于片段/JSON 上的 option-selected / selected
          select-placeholder="文本" 占位文本，缺省"请选择"
          select-multiple 多选：chips 回显、可逐个移除，值逗号合并
          select-max="5" 多选上限，超出时静默忽略新增
          select-tree 树形：option-parent 引用父级或 JSON children 表达层级，可折叠
          select-tree-strict 树形下关闭父子联动（默认勾父全选子、祖先半选）
          select-clearable 有值时显示清空按钮
          select-disabled 禁用：不可展开，值域同步 disabled
          select-required 透传 required 到值域（bny-form 校验）
          select-empty="文本" 无选项时的空态文案，缺省"无匹配数据"
          select-panel-max="300px" 面板最大高度，缺省 260px
          form-size="sm|lg" 尺寸变体（30px / 35px / 46px）
          hx-get / hx-post="地址" 远程选项源：未声明 hx-trigger 时首次展开自动请求一次；响应 HTML 片段 / JSON 自动识别， 由组件接管渲染（不做 htmx 交换）
          valid-msg-* / valid-rules 透传到值域，供 bny-form 取错误文案
          片段节点标记 说明
          <li option-value="1">北京</li> 选项：值缺省用 li 文本；option-disabled（停用）、 option-selected（默认选中）、option-parent（树形：引用父节点的 option-value，缺省即顶层）
          <li option-group>分组</li> 分组标题，不可选
          JSON 契约（数组或 {data|list|options:[...]}） 说明
          "北京" / 1 字符串/数字 → value 与显示文本相同
          {value, label, disabled, selected, level} 选项，与片段 li 的 option-* 一一对应
          {label, children:[...]} 分组标题（无 value，不可选），children 同级渲染
          {value, label, children:[...]} 树形父节点（有 value，配 select-tree），children 层级 +1
          {data:[...]} 对象包装（ThinkPHP/Laravel paginate 风格）自动解包
          事件：值变化时向值域派发原生 change / input， 并向扩展元素派发冒泡的 bny:select:change， detail = {values, items, elt}。
