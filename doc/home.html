为什么选择 BunnyUI

轻量、高效、服务端渲染友好的现代 UI 组件库

HTMX 扩展机制

基于 HTMX 扩展，通过 HTML 属性驱动组件行为，无需编写 JavaScript。声明式编程，拥抱超文本。

服务端零改造

ThinkPHP / Laravel / Django 照常返回 HTML，不需要写 JSON API。后端完全不需要知道前端在用什么。

完整设计系统

CSS 变量、暗黑模式、响应式一应俱全。完整的设计令牌体系，轻松定制主题。

XSS 防护

用户输入统一经过 escapeChars 转义，防止跨站脚本攻击。

SPA 扩展

可选的 SPA 扩展，为传统服务端渲染项目提供无刷新导航、URL 同步、SEO/GEO head 同步。

渐进增强

禁用 JavaScript 时链接照常跳转，不破坏可访问性和 SEO 爬虫抓取。
