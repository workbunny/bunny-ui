说明

数据来源：本页内容由仓库的 git tag 与 main 分支提交历史整理而成，每个节点的日期为该 tag 对应提交的日期。

维护方式：发布新版本后打上 vX.Y.Z 标签即可，本页按标签日期自动排序呈现；如需补充更详细的发布说明，直接在对应版本的 bny-timeline-content 中编辑文字即可。

节点配色含义：is-primary 当前最新 · is-info 重大里程碑（x.0.0） · is-warning 特殊版本（如回退） · is-success 常规更新。
